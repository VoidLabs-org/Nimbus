# Specs

Living docs that describe how Nimbus works **now**. Update them in the same PR as the code they describe.

- `product.md`: one-page product spec (goals, roles, in/out of scope)
- `<module>.md`: one per backend module (purpose, public interface, events published, tables)
- `openapi.yaml`: REST contract, agreed before coding

Plans for a change (feature specs and tickets) live in GitHub Issues, not here. Decisions live in `docs/adr/`.
